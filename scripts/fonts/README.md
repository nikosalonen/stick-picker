# Fonts for the share images

`scripts/prerender.mjs` draws the Open Graph share images with these fonts, so the build needs no network.

- Big Shoulders (ExtraBold) by Patric King, SIL Open Font License 1.1
- Atkinson Hyperlegible Next (Regular, Bold) by the Braille Institute, SIL Open Font License 1.1

Downloaded from Google Fonts. The website itself loads the same fonts from Google Fonts.
